# Tool Versions

The following software versions were used and tested during the development of this AES-128 Hardware Accelerator. 

> [!NOTE]
> Newer or older versions of these tools may work perfectly fine, but they might require minor command changes or have slightly different graphical interfaces.

### Open-Source Toolchain

*   **Verilog Simulator:** Icarus Verilog 12.0
*   **Verilator:** 5.012
*   **Synthesis:** Yosys 0.33
*   **Waveform Viewer:** GTKWave 3.3.116

### Intel / Proprietary Toolchain

*   **FPGA Implementation:** Quartus Prime 22.1 Lite Edition
*   **Simulation:** ModelSim - Intel FPGA Starter Edition 2020.1 (or Questa)

### Operating System Environment

*   **Linux:** Ubuntu 22.04 LTS (Primary development environment for open-source flow)
*   **Windows:** Windows 10/11 with WSL2 or native tool installations (Primary environment for Intel flow)
